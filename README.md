# 《BIG-5E大五碼補充字集》免費開源解決方案
字言字型成功開發以Big5-E（BIG-5 Extension Character Set）編碼規格的字型，目的為在解決早期使用了Big5-E編碼之文件能在現今正確顯示字形，而不會亂碼。
## 字型
本字型解決方案包括３款風格：

- 字言B5E外字集-黑體（`Fancy-B5E-EUDC-Hei`）
- 字言B5E外字集-宋體（`Fancy-B5E-EUDC-Sun`）
- 字言B5E外字集-楷體（`Fancy-B5E-EUDC-Kai`）

每款風格皆包含3,954個Big5-E字符及365個Big5-ET字符，這些字符不另外映射至正字碼位，僅適合在Big5-E規格文件作為Fallback字型顯示，不推荐使用字型內編碼輸入字符。

## 鳴謝
思源黑體、思源宋體、全字庫正楷體 提供字形。
